# Nostalji Erdek

Statik site (GitHub Pages). Dosyaları depoya yükleyin; `CNAME` alan adını belirler.

Yayına almadan önce:
1. Firebase > Firestore > Rules bölümüne `firestore.rules` içeriğini yapıştırıp yayınlayın.
2. Firebase > Authentication > Settings > Authorized domains listesine `nostaljierdek.com` ekleyin.
3. Yönetim paneline Google ile giriş yapın (kural, e-postası doğrulanmış hesabı kabul eder).
4. Cloudinary'de `nostalji-erdek` ön ayarını yalnızca görsel, en çok 10 MB olacak şekilde kısıtlayın.
5. Alan adının DNS kayıtlarını GitHub Pages'e yönlendirin.
